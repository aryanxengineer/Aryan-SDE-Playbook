## About This Repository

This repository documents my preparation for Software Development Engineer (SDE-1) roles.

My objective is not just to learn programming languages or frameworks, but to develop a strong understanding of software engineering fundamentals, problem-solving, backend development, and system design.

I will use this repository to maintain my learning notes, document daily progress, solve Data Structures and Algorithms problems, build practical projects, and track my overall development.

This is a **learning in public** initiative where consistency, practical implementation, and conceptual clarity matter more than simply completing a syllabus.

## Learning Methodology

I will follow a concept-first and implementation-driven approach.

For every important topic, I aim to:

1. Understand the underlying concept.
2. Learn why it exists and what problem it solves.
3. Understand its internal working wherever relevant.
4. Explore practical examples and implementation.
5. Practice interview-oriented questions.
6. Document my understanding in my own words.
7. Apply the knowledge in practical problems or projects.

I will prioritize understanding over memorization and avoid blindly copying solutions.
